# Notes vault

Open this folder as an Obsidian vault. Every `.md` file here is published to https://ananthp.vercel.app/notes, except:

- files with `draft: true` or `publish: false` in the frontmatter,
- files and folders whose name starts with `_` or `.` (for example `_templates/`),
- this README.

Setup guide: `docs/obsidian-notes.md` in the repository root.
